# Data dictionary

Generated by `scripts/generate_data_dictionary.py` from the warehouse schema and
`src/copenhagen_data_lab/database/catalog.py` (the same definitions appear in the
dashboard's Data Explorer). Types are DuckDB types.

Columns described as *Derived* are calculated by Copenhagen Data Lab; all other values
are official Statistics Denmark figures or codes from table FOLK1A.

## `raw_population`

*Layer:* raw · *Grain:* One row per requested cell per extraction request · *Rows in current snapshot:* 195,075

StatBank CSV records exactly as received; every column is a string.

| Column | Type | Definition |
|---|---|---|
| `extraction_run_id` | VARCHAR | Pipeline run that downloaded the records |
| `request_name` | VARCHAR | Bounded API request that returned the record |
| `OMRÅDE` | VARCHAR | Area code (StatBank) |
| `KØN` | VARCHAR | Sex code (StatBank) |
| `ALDER` | VARCHAR | Age code (StatBank) |
| `CIVILSTAND` | VARCHAR | Marital status code (StatBank) |
| `TID` | VARCHAR | Quarter code, e.g. 2026K3 |
| `INDHOLD` | VARCHAR | Observation value as text (persons) |

## `stg_population`

*Layer:* staging · *Grain:* area × sex × age × marital status × quarter · *Rows in current snapshot:* 193,725

Cleaned, typed observations. Missing values are NULL with value_status='missing'.

| Column | Type | Definition |
|---|---|---|
| `area_code` | VARCHAR | StatBank area code |
| `sex_code` | VARCHAR | TOT, 1 (men) or 2 (women) |
| `age_code` | VARCHAR | IALT (age total) or single year 0–125 |
| `marital_status_code` | VARCHAR | Marital status code (TOT = all) |
| `period_code` | VARCHAR | Original StatBank quarter code (e.g. 2026K3) |
| `population` | BIGINT | Persons on the first day of the quarter (official figure) |
| `value_status` | VARCHAR | reported or missing |
| `raw_value` | VARCHAR | Value exactly as delivered by StatBank |
| `source_request` | VARCHAR | Extraction request that delivered the observation |

## `mart_population_demographics`

*Layer:* mart · *Grain:* area × quarter × sex × age group (Denmark + focus municipalities) · *Rows in current snapshot:* 6,750

Age groups built from single-year ages; shares of the official age total.

| Column | Type | Definition |
|---|---|---|
| `area_code` | VARCHAR | StatBank area code |
| `area_name` | VARCHAR | Official English area name |
| `area_level` | VARCHAR | country, region, municipality or special_area (Christiansø) |
| `period_code` | VARCHAR | StatBank quarter code |
| `period_label` | VARCHAR | Display label |
| `period_index` | INTEGER | year × 4 + quarter − 1; contiguous integer used for ordering and lags |
| `sex_code` | VARCHAR | TOT, 1 (men) or 2 (women) |
| `sex_label` | VARCHAR | Official sex category label |
| `age_group` | VARCHAR | Derived age band (0–17, 18–29, 30–44, 45–64, 65+) |
| `age_group_order` | INTEGER | Sort order of the age group (youngest first) |
| `min_age` | INTEGER | Youngest single-year age in the band |
| `max_age` | INTEGER | Oldest single-year age in the band |
| `population` | BIGINT | Derived: sum of single-year counts (NULL if any are missing) |
| `age_total_population` | BIGINT | Official age total for the same area/quarter/sex |
| `share_pct` | DOUBLE | Derived: population / age_total_population × 100 |
| `single_year_cells` | BIGINT | Number of single-year ages in the band |
| `missing_cells` | BIGINT | Single-year ages with a missing value |

| Column | Type | Definition |

| `area_name` | VARCHAR | Official English area name |

| `period_code` | VARCHAR | StatBank quarter code |
| `period_label` | VARCHAR | Display label |
| `period_index` | INTEGER | year × 4 + quarter − 1; contiguous integer used for ordering and lags |
| `reference_date` | DATE | Date the population was counted (first day of the quarter) |
| `population` | BIGINT | Official population count |
| `yoy_comparison_period_code` | VARCHAR | Same quarter one year earlier, when that quarter exists |
| `population_year_earlier` | BIGINT | Population in the comparison quarter one year earlier |
| `yoy_change` | BIGINT | Derived: change vs same quarter one year earlier (persons) |
| `yoy_growth_pct` | DOUBLE | Derived: YoY growth (%) |
